# Customer Journey

> No es el journey del cajero. Es el journey del negocio que compra Atrio.
> Cada etapa puede hacer que un cliente gane o pierda un día de operación.

---

## Etapas

```
Compra → Configura → Opera → Crece → Recomienda
```

---

## Etapa 1: Compra

### Acciones del cliente

1. Busca "ERP para pequeña empresa" o "sistema de facturación"
2. Encuentra Atrio (web, recomendación, red social)
3. Lee sobre funcionalidades
4. Se registra para prueba gratuita o agenda demo
5. Decide comprar

### Dolor en esta etapa

| Dolor | Impacto |
|-------|---------|
| No encuentra información clara de precios | Abandona |
| Proceso de registro largo | Abandona |
| Demo no muestra su tipo de negocio | No compra |
| No hay prueba gratuita | No se arriesga |

### Lo que Atrio debe mostrar

- Precio claro (por tienda, por mes)
- "Funciona con o sin internet" (diferenciador LATAM)
- Demo interactiva o video de 2 minutos
- Testimonios de negocios similares

### Felicidad en esta etapa

> "En 5 minutos ya había creado mi cuenta y estaba viendo el sistema."

---

## Etapa 2: Configuración

### Acciones del cliente

1. Crea cuenta (email, contraseña, nombre del negocio)
2. Configura impuestos (IVA, ISLR, tasas)
3. Crea primer usuario (admin) y primer cajero
4. Carga productos (individual o masivo)
5. Configura impresora y escáner
6. Abre primera caja

### Dolor en esta etapa

| Dolor | Impacto |
|-------|---------|
| No sabe qué impuestos configurar | Abandona antes de vender |
| Carga de productos manual uno por uno | Abandona (tiene 500 productos) |
| No encuentra cómo configurar la impresora | Frustración |
| El asistente de configuración asume conocimientos | No avanza |

### Lo que Atrio debe hacer

- Onboarding paso a paso con tooltips
- Carga masiva desde Excel (plantilla descargable)
- Valores por defecto sensatos para LATAM (IVA 16%, facturación electrónica)
- "Modo piloto": todo configurado para que el cliente vea el sistema funcionando con datos de ejemplo

### Felicidad en esta etapa

> "En 20 minutos ya tenía mis productos cargados y una caja lista para vender."

---

## Etapa 3: Primera Venta

### Acciones del cliente

1. Cajero abre sesión
2. Busca primer producto
3. Agrega al carrito
4. Asigna cliente (o Consumidor Final)
5. Cobra
6. Imprime comprobante

### Dolor en esta etapa

| Dolor | Impacto |
|-------|---------|
| No encuentra el producto (mala búsqueda) | Cajero frustrado, cliente espera |
| Error al cobrar (stock, conexión) | Venta perdida |
| No sabe si la venta quedó registrada | Inseguridad |
| Comprobante no se imprime | Cliente insatisfecho |

### Lo que Atrio debe hacer

- Búsqueda instantánea que funciona desde el primer día
- Feedback claro: venta exitosa o error específico
- La venta NUNCA se pierde (guardar siempre, incluso offline)
- Probar la impresora durante la configuración

### Felicidad en esta etapa

> "La primera venta fue más rápida que con el sistema anterior. El cliente ni esperó."

---

## Etapa 4: Primer Cierre de Caja

### Acciones del cliente

1. Cajero cierra su turno
2. Sistema muestra conteo esperado vs real
3. Administradora revisa y confirma
4. Sistema guarda el cierre

### Dolor en esta etapa

| Dolor | Impacto |
|-------|---------|
| No sabe cómo cerrar caja | Cajero se va sin cerrar |
| Descuadre sin explicación | Desconfianza en el sistema |
| No puede reabrir para corregir | Frustración |
| Cierre no queda registrado | Problemas contables |

### Lo que Atrio debe hacer

- Botón visible "Cerrar Caja" al final del turno
- Descuadre muestra las transacciones que no cuadran
- Supervisor puede forzar cierre con nota
- Historial de cierres accesible para la administradora

### Felicidad en esta etapa

> "El cierre fue automático. Solo confirmé el conteo y listo."

---

## Etapa 5: Primer Reporte

### Acciones del cliente

1. Administradora o dueño consulta ventas del día/semana/mes
2. Revisa productos más vendidos
3. Revisa métodos de pago usados
4. Exporta a Excel o PDF

### Dolor en esta etapa

| Dolor | Impacto |
|-------|---------|
| No encuentra la sección de reportes | No usa reportes |
| Reporte no coincide con lo que esperaba | Desconfianza |
| No puede filtrar por fecha, producto, cajero | Reporte inútil |
| Exportación pierde formato | Trabajo extra |

### Lo que Atrio debe hacer

- Reportes predefinidos: Ventas del día, Ventas por producto, Ventas por cajero, Cierre de caja
- Filtros por fecha (presets: hoy, ayer, esta semana, este mes)
- Un clic para exportar a Excel
- Dashboard en la página de inicio: "Hoy vendiste: $X"

### Felicidad en esta etapa

> "Abrí el reporte, vi que las ventas subieron 15% esta semana, lo exporté y se lo mandé al dueño. 30 segundos."

---

## Etapa 6: Recuperación de Error

### Acciones del cliente

1. Cajero comete error (producto equivocado, cantidad incorrecta)
2. Cajero necesita anular una venta o devolver un producto
3. Cajero necesita ayuda (no sabe cómo hacerlo)
4. Administradora resuelve

### Dolor en esta etapa

| Dolor | Impacto |
|-------|---------|
| No puede anular una venta | Cliente insatisfecho o contabilidad incorrecta |
| Proceso de anulación es complejo | Cajero pierde tiempo |
| Anulación no queda registrada | Problemas de auditoría |
| Cajero no sabe qué hacer | Llama al supervisor, todos pierden tiempo |

### Lo que Atrio debe hacer

- Anulación visible en el historial con motivo obligatorio
- Devolución de productos (total o parcial)
- Registro de quién anuló y cuándo
- Límites: cajero puede anular ventas de hasta $X, supervisor sin límite

### Felicidad en esta etapa

> "El cliente trajo el producto equivocado. En 10 segundos hice la devolución y le vendí el correcto."

---

## Etapa 7: Crecimiento

### Acciones del cliente

1. Negocio crece: abre segunda tienda
2. Necesita más usuarios (cajeros, supervisores)
3. Necesita reportes consolidados
4. Contador pide más datos

### Dolor en esta etapa

| Dolor | Impacto |
|-------|---------|
| No sabe cómo agregar otra tienda | No crece con Atrio |
| Precio por tienda no está claro | Cambia de sistema |
| Reportes no consolidan | Trabajo manual |

### Lo que Atrio debe hacer

- Agregar tienda desde configuración (sin soporte técnico)
- Reportes multi-tienda con filtro por tienda o consolidado
- Roles y permisos granulares
- API para integración contable

### Felicidad en esta etapa

> "Abrí la segunda tienda en 10 minutos. Los reportes consolidados me mostraron cuál vende más."

---

## Etapa 8: Recomendación

### Condiciones para que el cliente recomiende

- ✅ El sistema nunca perdió una venta
- ✅ Los cajeros aprendieron rápido
- ✅ Los reportes son confiables
- ✅ El soporte respondió cuando hubo problemas
- ✅ El precio se justifica con el tiempo ahorrado

### Lo que NO lleva a recomendación

- ❌ "Tiene muchas funciones" (si no las usan)
- ❌ "Es bonito" (si es lento)
- ❌ "El vendedor fue amable" (si el producto falla)
