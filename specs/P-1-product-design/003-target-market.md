# Target Market

## Cliente primario

**Pequeña y mediana empresa (PYME) latinoamericana**

- 3–200 empleados
- Facturación entre $50K y $10M anuales
- Sectores: comercio, distribución, servicios
- Ubicación: Venezuela y Colombia (V1), expansión a México, Perú, Chile (V2+)
- Usuarios típicos dentro de la empresa: cajeros, contadores, administradores, gerentes de inventario, dueños

## Cliente secundario

**Empresas de software que necesitan un ERP white-label para sus propios clientes** (fase posterior, cuando exista API pública y multi-tenant maduro).

## Perfiles de usuario

| Perfil | Frecuencia de uso | Prioridad | Dispositivo |
|--------|------------------|-----------|-------------|
| Cajero / POS | Intensivo (8h/día) | Máxima | Desktop |
| Contador | Diario (4-6h) | Alta | Desktop |
| Administrador | Diario (2-4h) | Alta | Desktop |
| Gerente de inventario | Diario (2-4h) | Alta | Desktop |
| Dueño / Gerente general | Semanal (1-2h) | Media | Desktop + Móvil |
| Cliente / Proveedor | Ocasional | Baja | Web |

## Industrias target V1

- **Comercio** — tiendas, distribuidoras, ferreterías, farmacias
- **Servicios** — talleres, consultorías, mantenimiento
- **Alimentos y bebidas** — restaurantes, panaderías, pequeños procesadores

## Industrias que NO targeteamos V1

- Manufactura pesada (MRP complejo, BOM multi-nivel)
- Retail con decenas de tiendas físicas (POS multi-sucursal complejo)
- Salud (historias clínicas, facturación aseguradoras)
- Construcción (gestión de proyectos, avances de obra)
- Agroindustria (ciclos de cosecha, insumos variables)

## Dolor principal

Estas empresas hoy usan:
- Excel + facturador básico (caos)
- Sistemas legacy caros y difíciles de usar (Profit, Contasis)
- ERPs extranjeros que no entienden IVA/IGTF, multi-moneda, prestaciones sociales
- Soluciones locales frágiles que no escalan

Ninguna opción existente combina:
- Precio accesible (SaaS)
- Simplicidad moderna
- Localización real (no traducir, adaptar)
- Modularidad (pagar solo por lo que usas)
